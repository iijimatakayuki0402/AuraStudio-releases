# AuraStudio（配布用）

AuraStudio の Windows 版インストーラーを配布するためのリポジトリです。ソースコードは含みません。

## インストール

1. [最新のリリース](https://github.com/iijimatakayuki0402/AuraStudio-releases/releases/latest) の Assets から `AuraStudio-Setup-<版>.exe` をダウンロードします。
2. ダウンロードしたファイルを実行します（管理者権限は不要です）。
   - 「WindowsによってPCが保護されました」と表示された場合は、「詳細情報」→「実行」を選んでください（コード署名をしていないため）。
3. スタートメニューの「AuraStudio」から起動し、設定画面で APIキーを登録します。

## 更新

アプリは起動時に、このリポジトリの最新のリリースを確認します。新しい版があれば画面の上部に表示されるので、「更新する」を押してください。
インストーラーは、リリースに置いた `.sha256` と照合してから実行されます。
